### ICMP (Internet Control Message Protocol)

**Core Purpose**

* Used by hosts and routers to communicate network-level information.
* **Error reporting:** Signals when a host, network, port, or protocol is unreachable.
* **Diagnostic purposes:** Utilizes Echo request/reply messages, which are the foundation of the `ping` utility.

**ICMP Packet Format**

* ICMP messages are encapsulated and carried directly within IP datagrams.
* They consist of an 8-byte header followed by a data field.
* For error messages, the data field specifically carries the entire IP header plus the first 8 bytes of data from the original IP packet that caused the error.

**Common ICMP Message Types**

| ICMP Type | Message |
| :--- | :--- |
| `0` | Echo reply |
| `3` | Destination unreachable |
| `4` | Source quench |
| `5` | Redirect |
| `8` | Echo |
| `9` | Router advertisement |
| `10` | Router selection |
| `11` | Time exceeded |
| `12` | Parameter problem |
| `13` | Timestamp |

**ICMP Type 3: Destination Unreachable Codes**

| Code | Description |
| :--- | :--- |
| `0` | Net is unreachable |
| `1` | Host is unreachable |
| `2` | Protocol is unreachable |
| `3` | Port is unreachable |

**ICMP Type 11: Time Exceeded Codes**

| Code | Description |
| :--- | :--- |
| `0` | Time to Live exceeded in transit |
| `1` | Fragment reassembly time exceeded |

### Network Diagnostic Tools

**Ping (ICMP Echo)**

* The `ping` utility operates using specific ICMP messages to test reachability. It sends an ICMP Type 8, Code 0 message (Echo Request) to the destination.
* The receiving host acknowledges by returning an ICMP Type 0, Code 0 message (Echo Reply).

**Traceroute**

* Unlike Ping, Traceroute is not a standardized network utility, meaning its underlying implementation varies depending on the operating system.
* Depending on the tool or OS, traceroute probes can be sent using UDP, ICMP, or TCP packets. (For context: Linux/macOS typically use UDP, while Windows uses ICMP).

**Traceroute Challenges & Router Aliasing**

* **Multi-Path Topologies:** In a network with redundant paths (like a diamond topology where R1 can route through either R2 or R3 to reach R4), traceroute results can be confusing. Because traceroute sends multiple independent packets, load-balancing might send one packet through R2 and the next through R3, making the path look inconsistent.

* **Identifying Interfaces:** When traceroute returns a sequence of hops (e.g., `10.1.1.1` $\rightarrow$ `10.1.2.1` $\rightarrow$ `10.1.3.1` $\rightarrow$ `10.1.2.2`), it can be difficult to tell if those IP addresses belong to completely different routers or just different physical interfaces on the exact same router. 

* **MIDAR:** To solve this, researchers use **MIDAR** (Monotonic ID-Based Alias Resolution), a technique to map multiple IP addresses (aliases) back to a single physical router to figure out the true network topology.

### Network Enumeration

It is the systematic process of mapping a network to identify active devices, open ports, and specific running software. It is typically conducted in three distinct phases:

1. **Ping Sweep:** By sending ICMP Echo Requests (pings) to an entire subnet or range of IP addresses, you can identify active machines based on which ones reply.

2. **Port Scanning:** Once a host is found, the next step is a port scan to see which services it is hosting. You probe the ports by manipulating TCP flags:

	*   **Send SYN:** You initiate a TCP handshake by sending a SYN packet. 
	    *   *If Open:* The server replies with a SYN-ACK. 
	    *   *If Closed:* The server replies with an RST (Reset) packet.
	
	*   **Send FIN:** You send an unexpected FIN packet. This is often used to sneak past basic packet-filtering firewalls that only block incoming SYN packets.
	    *   *If Open:* According to standard TCP protocol, an open port will generally ignore an unexpected FIN packet (no response).
	    *   *If Closed:* A closed port will actively reply with an RST packet.

3. **Banner Grabbing**: This is too know the exact software version running on it (e.g., is the web server running Apache or Nginx? What specific SSH server is active?). It is the technique of connecting to an open port and capturing the initial greeting (banner) or header the software broadcasts. Common Tools:

    *   `curl -I <website>`: Fetches just the HTTP headers of a web server, which often clearly state the server software and version.
    *   `nc <IP> port`: Uses netcat to open a raw TCP connection to a specific port, allowing you to read the raw text banner returned by services like SSH or FTP.
